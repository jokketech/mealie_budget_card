# Mealie Budget Card v0.4.0-alpha.3.1

Tilføjer manuel produktsøgning i **Ret match**-dialogen.

Hvis den automatiske kandidatlisten ikke indeholder det rigtige produkt:

1. Tryk **Ret** ved ingrediensen.
2. Skriv et nyt søgeord, for eksempel `gulerødder`, `dijonsennep` eller `parmesan`.
3. Tryk **Søg** eller Enter.
4. Vælg et produkt fra op til 20 resultater.
5. Produktets EAN gemmes som en fast regel for den oprindelige ingrediens.

Søgningen bruger det allerede cachede Netto-feed og udløser derfor ikke ekstra EAN-priskald, før næste analyse.
